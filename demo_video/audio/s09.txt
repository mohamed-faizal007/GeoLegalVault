Now the core feature: verification. When we run it, the server does three things in order. It reads the stored file and recomputes its SHA-256. It compares that with the hash saved in the database at upload. And it reads the anchored hash from the Sepolia contract, live. All three are identical, so the result is VERIFIED. A database change alone, or a storage change alone, cannot produce a false VERIFIED, because the chain holds the original value.
