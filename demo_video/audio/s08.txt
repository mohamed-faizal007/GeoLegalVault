Now clearance. The throwaway Auditor has the lowest level, Public, and the lease is Confidential. In the repository the lease is simply not listed, because the server filters in the database query. Opening its exact link shows: that item couldn't be found. In the supplementary view, the real document and a made-up id give the same answer, 404 not found. We use 404 instead of 403, which means forbidden, because a 403 would confirm that the document exists. The refused attempt on the real document is still written to the audit log as ACCESS_DENIED. This is access control inside the application. It is not encryption.
