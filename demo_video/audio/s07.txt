Now, what exactly went on the blockchain. The Blockchain Anchor Record shows the network, sepolia, the contract address, the transaction hash and the block number. Below it, the app asks the contract live, and the on-chain hash equals the recorded hash. The smart contract, DocumentAnchor, stores only four things per document version: the hash, the version number, an event type, and the block time. The PDF, its filename and any person's name are not on-chain. A blockchain is public and permanent, so we keep confidential content off it. The contract also refuses a second anchor for the same version. On the public Etherscan page, the transaction shows Success on the Sepolia testnet, with a tiny fee. One service wallet in the backend signs every anchor. There is no Merkle tree: each file gets one hash.
