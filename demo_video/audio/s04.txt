Now the main flow. Authorized Staff opens Upload. The page shows the location the browser reports. On a real device that comes from the browser's GPS or Wi-Fi location. In this recording a test harness supplies it, and the label says so. The server still validates it. This location is inside the HQ zone. We enter a title, a type, the classification Confidential, and pick a sample PDF. On Upload, the server checks, in a fixed order: your token, your role, your location, then the file. Then it stores the file, computes the hash and writes an audit entry. The document is saved as a Draft. In this supplementary view, the real database shows the document row, and the version row with the SHA-256 fingerprint. The file itself is not in the database. It sits in private object storage, called RustFS here and Cloudflare R2 in production, under a server-made key that includes the hash. The uploader then submits it for review, and the status becomes Submitted. In the app, Version History shows the fingerprint, shortened. A SHA-256 hash turns any file into 64 characters, and changing one byte changes all of them. The bucket listing confirms the stored object. The bucket is private. Downloads use a link that expires in sixty seconds.
